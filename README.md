# DKGST - GST Accounting System
## Blazor WebAssembly + ASP.NET Core API

A comprehensive modular monolith GST Accounting system for Indiana with multi-company support, role-based permissions, and multi-language support.

### Features
- ✅ Modular Architecture (Identity, Accounting, Inventory)
- ✅ Multi-Company Support (Separate Database per Company)
- ✅ Role-Based Access Control (RBAC)
- ✅ Multi-Language Support (English, Spanish, Hindi)
- ✅ PostgreSQL / SQL Server Support
- ✅ JWT Authentication
- ✅ Blazor WebAssembly UI
- ✅ RESTful API Backend
- ✅ Company Selector & Permission-Based Menu
